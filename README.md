# XYStation

GodTalk 的个人作品站。纯静态页面，可直接部署到 Gitee Pages。

仓库：<https://gitee.com/GodTalk/xystation>

## 本地预览

用浏览器打开 `index.html`，或在目录里启动任意静态服务器。

## 推送到 Gitee

```bash
git init
git add .
git commit -m "first commit"
git remote add origin https://gitee.com/GodTalk/xystation.git
git push -u origin master
```

## 开通 Gitee Pages

1. 打开仓库 → **服务** → **Gitee Pages**
2. 分支选 `master`，目录选 `/`
3. 启动后访问：`https://goatalk.gitee.io/xystation/`
